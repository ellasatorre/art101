Project 1

I made a grid based stamp and mouse based brush drawing program. I had lots of fun with this. I've made a drawing program utilizing p5.js before, but not with grid based stamps. I enjoyed creating brushes and stamps to fit my aquatic theme. I also liked creating my images with this program. Having so many stamps and interesting textured brushes is so fun to play with. I tried to make some scenes that were more like fish swimmin in a kelp forest, but others were more abstract and just me having fun with the brushes and stamps I made. One thing that I struggled with was combining the template code together, as for a while I couldn't figure out why the stamps were working but the brushes were not. I eventually figured it out and both functions work.

    Additional Work
  • combined the paint and stamp program
  • utilized colorMode(HSB) to create a color changing brush
